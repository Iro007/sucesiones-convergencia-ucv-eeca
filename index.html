Fundamento Teórico

Definiciones Formales y Jerarquía del Curso

Sobre un espacio de probabilidad (Ω, ℱ, P), una sucesión {Xn} asigna a cada n ∈ ℕ una variable aleatoria con función de distribución Fn(x) = P[Xn ≤ x].

Convergencia en Probabilidad

01 · Eje Tema 5
{Xn}P→X  ⇔  límn→∞P[|Xn − X| ≥ ε] = 0 para todo ε > 0

Def. 5.1.2 (Ramírez y Vásquez, p. 153): Si X = Xc = c (constante degenerada), se denomina convergencia estocástica.

Convergencia en Distribución

02 · Eje Tema 5
{Xn}F→X  ⇔  límn→∞Fn(x) = FX(x) en todo punto de continuidad x de FX

Def. 5.1.1 (p. 153): Exigida en los puntos de continuidad de la función de distribución límite FX. Por el Teor. 5.1.1, hacia una constante Xc = c equivale a →P.

Convergencia en Media Cuadrática (L2)

03 · Rincón, Cap. 7
{Xn}L²→X  ⇔  límn→∞E[|Xn − X|2] = 0

Rincón (2010, p. 294): Exige segundos momentos finitos. En el ejemplo central, E[(Xn − 50)2] = 100/n → 0.

Convergencia Casi Segura (c.s.)

04 · Rincón, Cap. 7
{Xn}c.s.→X  ⇔  P[límn→∞Xn = X] = 1

Rincón (2010, p. 290): Jerarquía de implicaciones: (c.s. ó L2) ⇒ →P ⇒ →F (Fig. 7.5, p. 298).

Ejercicio 01 · Convergencia en Probabilidad (Teor. 5.1.2)

Cota suficiente de Tchebycheff (n ≥ 500) vs. mínimo bajo el modelo normal (n = 97)

▼

Planteamiento: Sean X1, …, Xn ∼ N(50, 100) independientes e idénticamente distribuidas (μ = 50, σ = 10). Con observaciones normales i.i.d., Xn ∼ N(50, 100/n) es exactamente normal para todo n ≥ 1. Se desea garantizar P[|Xn − 50| < 2] ≥ 0,95.

(a) Tchebycheff (sin normalidad):   1 − 1004n ≥ 0,95  ⇒  25n ≤ 0,05  ⇒  n ≥ 500
(b) Modelo normal exacto:   2Φ(0,2√n) − 1 ≥ 0,95  ⇒  0,2√n ≥ z0,975 ≈ 1,959964  ⇒  n ≥ 96,0365  ⇒  n = 97
Interpretación exacta: Mediante la cota de Tchebycheff, n ≥ 500 garantiza el objetivo (cota suficiente válida sin asumir normalidad). Bajo el modelo normal del ejercicio, n = 97 es el mínimo exacto: con n = 96 se obtiene P[|X96 − 50| < 2] ≈ 0,94995648 < 0,95 (no cumple), mientras que con n = 97 se alcanza ≈ 0,95113544 ≥ 0,95 (cumple).
Ejercicio 02 · Convergencia en Distribución (Teor. 5.2.4)

Teorema de Moivre–Laplace para X ∼ b(10; 0,5) con corrección por continuidad

▼

Enunciado (Ramírez y Vásquez, pp. 159–160): Sea X el número de caras en 10 lanzamientos independientes de una moneda justa, X ∼ b(10; 0,5) con PX(x) = C(10, x)(0,5)10·I{0,…,10}(x), μ = np = 5 y σ2 = npq = 2,5 (σ = √2,5 ≈ 1,581139). Se calcula P(3 ≤ X ≤ 5) y se compara con la aproximación normal con corrección por continuidad en [2,5; 5,5].

P(3 ≤ X ≤ 5) = 120 + 210 + 2521024 = 5821024 = 0,568359375 ≈ 0,56836
z1 = 2,5 − 5√2,5 = −√2,5 ≈ −1,581139,    z2 = 5,5 − 5√2,5 = 1√10 ≈ 0,316228
Método de cálculo Expresión Resultado
Valor binomial exacto redondeado (5 dec.) 582 / 1024 = 0,568359375 ≈ 0,56836
Aproximación con la tabla del curso (2 dec., p. 159) Φ(0,32) − Φ(−1,58) ≈ 0,6255 − 0,05705 ≈ 0,56845
Aproximación normal con corrección por continuidad sin redondear z Φ(1/√10) − Φ(−√2,5) ≈ 0,624085 − 0,056923 ≈ 0,56716
Distinción clave: 0,56836 es el valor binomial exacto redondeado; 0,56845 proviene de la tabla normal del curso a 2 decimales; y 0,56716 es la aproximación normal con corrección por continuidad evaluada sin redondear los valores estandarizados z1 y z2.
Ejercicio 03 · Consistencia de la Varianza Muestral (Teor. 5.1.3)

Demostración de {Sn2} →P σ2 para cualquier ε > 0

▼

Hipótesis (Ramírez y Vásquez, p. 155): Sean X1, …, Xn ∼ N(μ, σ2) i.i.d. (μ = 50, σ2 = 100). Para todo n ≥ 2, (n − 1)Sn2/σ2 ∼ χ2(n − 1), por lo que E[Sn2] = σ2 y Var(Sn2) = 2σ4/(n − 1).

Para cualquier ε > 0 fijo y todo n ≥ 2 (Tchebycheff):   0 ≤ P[|Sn2 − σ2| ≥ ε] ≤ mín(1; 2σ4(n − 1)ε2) ≤ 2σ4(n − 1)ε2
Al fijar σ2 y ε > 0:   límn→∞ 2σ4(n − 1)ε2 = 0  ⇒  límn→∞P[|Sn2 − σ2| ≥ ε] = 0  ∀ ε > 0

Ilustración numérica (σ2 = 100, ε = 15, n = 1001): P[|S10012 − 100| ≥ 15] ≤ mín(1; 2(100)2/(1000·152)) = 20.000/225.000 = 4/45 ≈ 0,0889.

Conclusión: Por el teorema del emparedado, el límite es 0 para cualquier ε > 0 arbitrario, demostrando que {Sn2} →P σ2 (estimador consistente, Def. 5.1.2 y Teor. 5.1.3).
Contexto Actuarial

Estabilidad de la Media de Cartera

En una cartera de n pólizas con siniestros diarios normales independientes e idénticamente distribuidos Xi ∼ N(50, 100), la media muestral Xn tiene media constante μ = 50 USD y varianza Var(Xn) = 100/n. Bajo estos supuestos del modelo, al aumentar n disminuye la variabilidad de la media: la probabilidad de desviarse 2 USD o más respecto a la prima pura desciende de ≈ 31,73% (n = 25) a ≈ 0,0063% (≈ 6,33 × 10−5 con n = 400) y a ≈ 7,74 × 10−6 (n = 500). Con observaciones normales i.i.d., la distribución de Xn es normal exacta para todo n.
